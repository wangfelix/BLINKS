# deface provides the CenterFace detector + the bundled centerface.onnx model.
# It pulls in opencv-python (full) transitively, and CenterFace runs the ONNX
# model through OpenCV's DNN module (cv2.dnn) -- no onnxruntime needed on CPU.
#
# IMPORTANT: do NOT also `pip install opencv-python-headless`. Both packages
# install into the same cv2/ directory; having both (or uninstalling one)
# corrupts the import. If this runs on a headless server and `import cv2` fails
# with "libGL.so.1: cannot open shared object file", install the system libs
# instead of swapping opencv builds:
#     sudo apt-get install -y libgl1 libglib2.0-0
#
# Verified working on Python 3.13.
